# Плейбук siderev2.yml - Включение реструктуризации v2

Плейбук для активации функции реструктуризации v2 в 1С:Предприятие 8.3.18+

## Предварительные требования

1. Успешно выполнен основной плейбук `side.yml`
2. Установленный JRE (через роль `install_JRE`)
3. Доступ к серверам под учетной записью с sudo-правами

## Переменные конфигурации

### Основные параметры

| Переменная | Значение по умолчанию | Описание |
|------------|-----------------------|----------|
| `jre_package_path` | `/distr/deb/for_jre` | Путь к пакету JRE |
| `jre_version` | `jre-8u371-linux-x64.deb` | Версия JRE |
| `rv2_enabled` | `true` | Флаг активации реструктуризации |

### Пути установки

```yaml
java_home: "/usr/lib/jvm/jre1.8.0_371"
jre_install_dir: "/opt/jre"
````

## Инструкция по запуску

### 1. Подготовка

Поместите пакет JRE в указанную директорию:

```bash
mkdir -p /distr/deb/for_jre
cp jre-8u371-linux-x64.deb /distr/deb/for_jre/
```

### 2. Запуск плейбука

```bash
ansible-playbook -i hosts siderev2.yml -K
```

### 3. Проверка результатов

```bash
ansible -i hosts serv1C -m shell -a "/opt/1C/v8.3/x86_64/ragent -v"
```

В выводе должна быть строка: `Реструктуризация v2: доступна`

## Состав выполняемых задач

1. **Установка JRE** (если не установлен)
2. **Настройка переменных окружения**:
    - Добавление JAVA\_HOME
    - Обновление PATH
3. **Активация функции**:
    - Проверка версии платформы
    - Настройка параметров кластера

## Важные замечания

⚠️ **Внимание!** После выполнения:

1. Закомментируйте строку в `/etc/environment`:
```bash
#PATH=$PATH:$JAVA_HOME/bin
```
2. Для последующих плейбуков раскомментируйте обратно

## Пример inventory

```ini
[serv1C:vars]
jre_package_path = "/opt/distr/jre"
jre_version = "jre-8u381-linux-x64.deb"
rv2_enabled = true
```

## Troubleshooting

| Проблема | Решение |
|----------|---------|
| JRE не устанавливается | Проверить права на файл пакета |
| Ошибка JAVA\_HOME | Убедиться в правильности пути установки |
| Функция не активируется | Проверить версию платформы (требуется 8.3.18+) |
