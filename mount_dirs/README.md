# Роль `mount_dirs` - Настройка LVM и точек монтирования

Роль для автоматизированного создания LVM-структуры, файловых систем и настройки точек монтирования.

## Назначение

Автоматизирует:
- Создание физического тома (PV), группы томов (VG) и логических томов (LV)
- Форматирование разделов в указанную файловую систему
- Миграцию данных с существующих точек монтирования (при необходимости)
- Настройку постоянного монтирования через /etc/fstab

## Переменные

### Основные параметры

| Переменная | По умолчанию | Обязательная | Описание |
|------------|--------------|--------------|----------|
| `disk_device` | `/dev/sdb` | Да | Блочное устройство для LVM |
| `vg_name` | `data_vg` | Да | Имя группы томов |
| `fs_type` | `ext4` | Нет | Тип файловой системы |

### Структура LVM

Определяется в переменной `lvm_structure` (список словарей):

```yaml
lvm_structure:
  - name: "home_lv"       # Имя логического тома
    size: "100G"          # Размер (может быть в %FREE)
    mount: "/home"        # Точка монтирования
    migrate: true         # Нужно ли переносить данные
    create_dir: false     # Нужно ли создавать директорию
```

## Зависимости

- Пакет `lvm2` (устанавливается ролью автоматически)
- Доступное блочное устройство для LVM
- Достаточно свободного места для миграции данных (если требуется)


## Особенности работы

### Миграция данных:
- Для томов с `migrate: true` создается временная точка монтирования в `/mnt/new_*`
- Данные копируются с исходной точки монтирования
- После копирования выполняется перемонтирование на новый том

### Создание директорий:
- Если `create_dir: true` - роль создаст указанную директорию
- Для системных директорий (/home, /var/log и т.д.) обычно `create_dir: false`

### Размеры томов:
- Можно указывать в гигабайтах (например "100G")
- Можно использовать "100%FREE" для всего оставшегося места

## Troubleshooting

| Ошибка | Решение |
|--------|---------|
| Устройство не найдено | Проверить `disk_device` и доступность устройства |
| Недостаточно места | Увеличить размер устройства или уменьшить размеры томов |
| Ошибка монтирования | Проверить существование точки монтирования и права |
| Ошибка миграции | Проверить свободное место в /mnt для временных точек |
